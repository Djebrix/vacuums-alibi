One line, at most 200 characters: the excuse a robot vacuum gives for missing a spot.

> I did not miss that spot. My sensors logged it as a rug, and rugs have diplomatic immunity in this house.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`, deterministic, with a 1–200 character guard.
